# JARVIS AI Assistant 🤖

A futuristic Iron Man-inspired AI assistant built using HTML, CSS, JavaScript, Express.js, and Groq AI.

JARVIS features:
- Real-time AI chat
- Voice replies
- Microphone input
- Cinematic HUD interface
- Particle effects
- Radar animations
- Responsive mobile design
- Futuristic startup screen

---

# Tech Stack

## Frontend
- HTML
- CSS
- JavaScript

## Backend
- Node.js
- Express.js

## AI
- Groq API
- Llama 3.3 70B Model

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/jarvis-ai.git
```

---

# Backend Setup

## Open backend folder

```bash
cd backend
```

## Install dependencies

```bash
npm install
```

## Create `.env`

```env
GROQ_API_KEY=your_api_key
PORT=5000
```

## Start backend server

```bash
npm start
```

Backend runs on:

```txt
http://localhost:5000
```

---

# Frontend Setup

Open `frontend/index.html`

OR run using Live Server extension in VS Code.
